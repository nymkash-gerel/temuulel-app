# Demo Video Script — Meta App Review
# pages_messaging permission
# Нийт хугацаа: 2-3 минут

---

## Бэлтгэл (бичлэг эхлэхээс өмнө)

- Дэлгэцийн бичлэг хийх програм нээ (QuickTime / Loom / OBS)
- 2 цонх нэгэн зэрэг нээлттэй байх:
  1. **Facebook Page** (хэрэглэгчийн чатын дуурайлт)
  2. **Temuulel Dashboard** (захиалга харагдах)
- Дэлгэц цэвэр, notification-ууд хаалттай байх

---

## 0:00 — 0:15 | Танилцуулга

**Хэлэх зүйл (дуу бичих эсвэл subtitle):**
> "This is Temuulel — an AI business automation platform for Mongolian small businesses.
> We use the pages_messaging permission to receive customer messages and automatically process orders through Facebook Messenger."

**Дэлгэцэнд харуулах:**
- Temuulel dashboard нүүр хуудас
- Store name харагдах

---

## 0:15 — 0:45 | Хэрэглэгч мессеж бичнэ

**Хэлэх зүйл:**
> "A customer sends a message to the business's Facebook Page asking about a product."

**Дэлгэцэнд харуулах:**
1. Facebook Page → Inbox нээ
2. Test хэрэглэгчийн нэрнээс мессеж бич:
   ```
   "Хар өнгийн S размер байна уу?"
   ```
3. 2-3 секунд хүлээ
4. Bot автоматаар хариулж байгааг харуул:
   ```
   "Тийм, байна ✅ Үнэ: 45,000₮
   Захиалах уу?"
   ```

**Хэлэх зүйл:**
> "Our AI automatically responds in Mongolian with product availability and pricing."

---

## 0:45 — 1:30 | Захиалгын олон алхамт яриа

**Хэлэх зүйл:**
> "When the customer wants to order, our system collects their information step by step."

**Дэлгэцэнд харуулах:**
1. Хэрэглэгч:
   ```
   "Тийм, захиалъя"
   ```
2. Bot:
   ```
   "Нэрээ бичнэ үү:"
   ```
3. Хэрэглэгч:
   ```
   "Болормаа"
   ```
4. Bot:
   ```
   "Хүргэлтийн хаягаа бичнэ үү (дүүрэг, хороо, байр):"
   ```
5. Хэрэглэгч:
   ```
   "БЗД 3-р хороо, 45 тоот"
   ```
6. Bot:
   ```
   "Утасны дугаараа бичнэ үү:"
   ```
7. Хэрэглэгч:
   ```
   "99001234"
   ```
8. Bot баталгаажуулалт:
   ```
   "✅ Захиалга баталгаажлаа!
   📋 Захиалгын дугаар: ORD-001
   📦 Хар S размер — 45,000₮
   🚚 Хүргэлт: 5,000₮
   💰 Нийт: 50,000₮
   📍 БЗД 3-р хороо, 45 тоот
   📱 99001234
   Жолооч тантай холбогдоно 📞"
   ```

---

## 1:30 — 2:00 | Dashboard-д захиалга харагдана

**Хэлэх зүйл:**
> "The order is instantly recorded in the business dashboard."

**Дэлгэцэнд харуулах:**
1. Temuulel Dashboard → Orders хуудас нээ
2. Шинэ захиалга "ORD-001" жагсаалтад харагдаж байгааг zoom хий
3. Захиалгын дэлгэрэнгүйг нээ:
   - Хэрэглэгчийн нэр
   - Хаяг
   - Утас
   - Бараа + үнэ
   - Хүргэлтийн статус

**Хэлэх зүйл:**
> "Business owners can manage all orders from a single dashboard without manually reading each Messenger chat."

---

## 2:00 — 2:20 | Operator mode (нэмэлт)

**Хэлэх зүйл:**
> "At any time, the business owner can take over the conversation manually."

**Дэлгэцэнд харуулах:**
- Dashboard → Conversations → "Take over" товч дар
- Хэрэглэгчид гараар мессеж бичих боломж

> 2. Send automated responses for product inquiries and order confirmations
> 3. Never initiate unsolicited messages
> Full privacy policy: temuulel-app.vercel.app/privacy"

**Дэлгэцэнд харуулах:**
